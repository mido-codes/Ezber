# Ezber

Ezber (Turkish for "memorization") is a Quran memorization and listening app for iPhone and Android. It is built for learners who memorize in short sections, repeat each verse, and read Roman transliteration rather than the Arabic script.

## What it does

- Pick a surah and a section — for example Ar-Rahman, verses 1–5 — and set how many times each verse repeats.
- Listen with the transliteration on screen, following the verse as it plays.
- Save the setup as a preset and reload it in one tap.
- Choose a different reciter per surah.
- Keep playing in the background, with lock-screen controls and CarPlay showing the verse like lyrics.
- Track what has been drilled and keep verse-level notes.

## Platforms

iPhone first, then Android, each with native background audio and car support. The same MVP also ships as a web app and installable PWA in `web/` (everything except CarPlay). Everything works offline and no account is required.

## Status

Early MVP, under active development.
